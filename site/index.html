Inside AI Video Studio +

Challenge

Creating a short video requires coordinating scripts, media, narration, captions, and rendering.

Approach

I connected these stages into a single workflow that turns a topic into a short-form video.

Key engineering

  • FastAPI backend coordinates generation tasks.

DocShield

A multi-format document reader with file-signature verification, extension-spoofing detection, OCR, and structured inspection.

PythonStreamlitPyMuPDFOCR
Open app ↗Source code ↗

Hosted on Streamlit. If inactive, the app may need to wake up before loading.

Inside DocShield +

Challenge

Documents arrive in different formats, and a filename extension does not reliably identify file content.

Approach

I built a document inspection tool that checks file signatures and extracts content across supported formats.

Key engineering

  • File-signature checks identify extension mismatches.
  • PyMuPDF and pdfplumber extract PDF content.
  • OCR supports scanned text; Streamlit provides the inspection interface.

What this demonstrates

Defensive input handling and multi-format document processing. Signature checks are not malware scanning.
